# Автор

Нерсисян Валерия 4-МД-15
Персональный сайт-визитка графического дизайнера.

## О проекте

Сайт представляет информацию обо мне, моих навыках,
образовании, работах и контактных данных.

Основная визуальная концепция построена на крупной типографике,
асимметричной композиции и сочетании кремового, чёрного,
кораллового, розового и мятного цветов.

## Технологии

- HTML5
- CSS3
- JavaScript
- CSS Grid / Flexbox
- Адаптивная вёрстка

## JavaScript

На сайте реализованы:
- интерактивный курсор в форме звезды;
- анимации появления элементов при прокрутке;
- интерактивные карточки проектов;
- изменение изображений кейсов при наведении;
- кнопка копирования контакта;
- отображение текущего времени.

## Адаптивность

Сайт адаптирован под компьютеры, планшеты и мобильные устройства.
На сенсорных устройствах кастомный курсор отключается.

## Использование ИИ

В процессе разработки использовался ChatGPT.

ИИ применялся для помощи с:
- CSS и JavaScript;
- интерактивными элементами;
- адаптивностью;
- проверкой и исправлением кода.

### Пример промпта

«Сделай карточки кейсов интерактивными: в обычном состоянии
изображения должны быть серыми, а при наведении возвращать
свои исходные цвета. Добавь увеличение изображения и
анимацию карточки, не перекрашивая сами изображения
в цвета интерфейса».

### Самостоятельные изменения

После работы с ИИ самостоятельно были скорректированы
цветовая палитра, внешний вид курсора, интерактивность
кейсов, расположение элементов и итоговое визуальное оформление.

## Структура

- `index.html` — структура сайта
- `style.css` — стили и адаптивность
- `script.js` — интерактивные функции
- `images/` — изображения проектов
